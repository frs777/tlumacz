# Agent Translacyjny

Narzędzie CLI inteligentnego tłumaczenia oparte na AI z interaktywnym interfejsem czatu.

## Wersja

Bieżąca wersja: **0.1.0**

## Funkcje

- 🌍 **Interaktywny Interfejs Czatu**: Piękny interfejs terminalowy zbudowany z React + Ink
- 💬 **Historia Wiadomości**: Wyświetl wszystkie swoje wiadomości z znacznikami czasowymi
- 🎯 **Proste Komendy**: Wpisz 'exit' lub 'quit', aby wyjść
- 🔧 **Nowoczesny Stos**: Zbudowany z TypeScript i modułów ESM

## Wymagania

- Node.js v20 lub nowszy

## Instalacja

```bash
npm install
```

## Użycie

### Tryb Rozwoju
```bash
npm run dev
```

### Budowanie
```bash
npm run build
```

### Produkcja
```bash
npm start
```

## Jak Używać

1. Uruchom CLI za pomocą `npm run dev`
2. Wpisz swoje wiadomości w polach wejściowych na dole
3. Naciśnij Enter, aby wysłać
4. Wyświetl historię swoich wiadomości w głównym obszarze
5. Wpisz 'exit' lub 'quit', aby zamknąć aplikację

## Rozwój

Ten projekt używa:
- TypeScript do bezpieczeństwa typów
- React + Ink dla interfejsu terminalowego
- Modułów ESM dla nowoczesnego JavaScript
